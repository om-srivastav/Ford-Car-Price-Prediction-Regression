# 🚗 Ford Car Price Prediction using Machine Learning

A Machine Learning project that predicts **Ford used car prices** using **Linear Regression**. This project covers the complete ML workflow, including data preprocessing, exploratory data analysis (EDA), model training, and performance evaluation.

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
